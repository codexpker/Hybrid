# Hybrid V1：2026-11-04 工程与实验状态

本页是已验收记录的公开摘要，不是新的训练命令、模型选择依据或收益声明。研究整体为 **HOLD**。模型架构在最近固定实验期间保持不变，原始 TimeRadar 八基准没有重跑。

## 当前代码包含什么

|部分|共享实现|范围|
|---|---|---|
|完整候选|`model.py`、`config.py`|512点历史、32点预测、按可见观测归一化、重建与预测两条合法时间路径|
|时频表示|`fractional.py`|外置 TimeRadar FRFT；局部窗100；不分发作者权重或源码|
|因果时序编码|`temporal.py`|外置 TimesFM 3.0 因果块的轻量配置；不使用大模型预训练权重|
|滞后交互|`lag.py`|分别表达Self和Cross的有限合法延迟；不是已证明的物理时滞估计器|
|多视图融合|`multiview.py`|外置LEFT滤波/交互子组件和固定简单融合控制|
|训练与适配|`training.py`、`stage2_adaptation.py`、`event_adaptation.py`|源自监督、独立Z/U/F接口及匹配正常对照|
|污染实验|`contamination_data.py`、`h5_evaluate_cli.py`|固定donor与正常来源替换对照；Huber/MSE比较，不将Huber自身称为创新|
|评分与评价|`readout.py`、`scoring.py`、各具名评价入口|保存原始分数/索引/有效性；固定阈值、完整事件、误报、延迟和官方Aff依赖|
|受控诊断|`controlled_mechanism.py`、`controlled_wave.py`、`controlled_wave_evaluation.py`|固定输入、同次前向诊断归档和后置标签评价；不是新的网络|
|恢复与交接|`controlled_wave_recovery.py`、`foreground_completion.py`|修复RNG证据序列化、复用完整银行、有界作业退出交接|

以上V1文件均在 `src/hybrid_tsad/hybrid_v1/`，交接帮助模块位于包根。来源与真实函数映射见 [paper_module_map.md](paper_module_map.md)，架构开关见 [architecture.md](architecture.md)。旧预测原型、基线与负面结果保持独立身份。

Cross延迟变化中，单个报警匹配一个长事件使严格事件F1为1，但只命中1/768异常点、首报延迟67点、连续确认漏检。不得将该事件F1解释为持续高敏感或真实有向滞后识别。Self全正常输入的full2025误报117/2048，高于Self-off的100/2048；正常误报也必须与排序指标一起报告。

完整70结果、81比较和12语义对照经过独立NumPy复算，最大误差8.88e-16；官方Aff在164个报警流上回放78次，误差为0，合法无定义/无真事件结果原样保留。没有用测试标签搜索阈值、模型或种子，没有因负例删除案例。独立审查是同模型家族共享工作区下的职责分离，不是外部双盲审稿。

## 如何理解这次更新

本次同步包含此前已完成的完整V1及共享实验/评价代码。最近更新集中在事件支持、正常适配对照、污染构造、公开读出、连续分数归档、合法NA与事件评价、RNG恢复和诊断工具；没有根据本轮测试结果新增网络或调整结构。实现和实验已经完成的部分应与仍未证实的稳定检测收益、融合创新、污染鲁棒主张分别理解。
