# Fixed F comparison of three detector initializations

This is a single-seed public-support adaptation comparison on the existing PSM and SMD machine-3-2 tasks. Three existing Z checkpoints supply the official TimeRadar initialization, normally reconstructed source continuation, and point-weighted real-source-event supervision. Each receives the identical target support plan and fixed 240-update F rule. The official initialization plus matched F is a project control.

The support label budget per task is one complete abnormal event plus 512 normal observations. PSM uses the event [3248,3439) and normal block [92,604); SMD machine-3-2 uses [3080,3917) and [161,673). They provide 92/738 legal positive and 413 legal normal endpoints respectively. All 100 observations of every training window stay within their own support block. The learner receives the two arrays and the sealed draw plan. Public truth is used to construct the support set. SMD machine-3-3 has no eligible complete-window support event and remains NA.

Each update has 32 normal-copy windows, 15 positive endpoints (five from each of three time strata) and 15 paired normal endpoints. The pair uses log1p(V/a_F), softplus margin one, coefficient one, and legal-positive-count weights. The normal loss uses all positions, variables and ten copies. Across 240 updates the exposures are 7,680 normal reconstruction windows plus 3,600 positive and 3,600 matched normal windows. Repeated exposures are drawn from the same one event. The common task-specific a_F is the official initialization's median V over all 413 normal support endpoints, protected below by 1e-8.

Only the native decoder updates, with fresh AdamW under the existing source-training settings and 24-update warmup. Each native input is one 100-point window with ten fixed complementary masks in eval mode. The deployed score remains raw native endpoint V, with sample variance and the original scaler. Step 240 supplies the endpoint; the Z row is the separately archived pre-adaptation reference.

PSM ranking and operation both use the fixed 64,728-point suffix for this experiment. The historical full-test ranking table retains its separate axis. All 512 PSM CAL points have attack labels. SMD machine-3-2 uses 14,746 QUERY points and its nominal-normal CAL. Each method uses its own CAL V, q99/higher and strict exceedance. The normal support block is excluded from CAL. Three-confirmation starts at the third consecutive crossing without backfill. Event matching and any-hit are recorded separately. No long event qualifies in the SMD suffix.

NASA generalization and SMD28 historical tests remain archived. This study measures target-label-supported F and its dependence on initialization. Its conclusions apply to one fixed support event and one training seed in each task.
