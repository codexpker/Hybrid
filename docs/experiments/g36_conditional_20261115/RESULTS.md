# G36五周仿真：有限条件正常性机制验证

## 科研结论

本轮实现、匹配训练及固定评价已完成。**本次条件神经学习机制不获支持；不是对所有条件建模或第二篇研究目标的否定。** 全部结果为仿真开发/机制证据，不是真实独立确认，不是混合无标签鲁棒性证据。

最关键的事实不是AP差值，而是**正常SELECT选择了条件候选的step0初始化**。其3000步训练真实完成、条件梯度有效，但每个已登记训练检查点的正常SELECT损失均高于初始化：3.420326（step0）对4.316951（step3000）。正式分数实际退化为FIT标准化响应块上的固定Student-t先验，不能称为学到了正常条件关系。未改选末次权重，未追加末次QUERY评价。

去条件神经对照选择step3000，LEFT选择step2100。三方法同seed2025、3000更新上限、共同FIT端点计划；两个神经密度模型初始参数逐张量一致。LEFT沿用官方原生损失/评分，输入9通道而评分预定义4响应；Ridge使用全部48历史点，TCN实际感受野31点。没有因此声称模型容量、输入使用方式或历史利用完全相同。

## 事件计数、可观测性和证据边界

所有方法any-hit均3/3；三连命中除去条件神经对照1/3外均3/3。这不等于没有长漏检。正常轴与每个故障轴分别切分报警事件，再进行一对一匹配；候选/LEFT的严格一对一Precision分别2.1739%/2.8846%，F1分别4.2553%/5.6075%，重复报警碎片不反复算作新故障命中。全部严格点、三连点、事件P/R/F1、误报片段、延迟及最长漏段见CSV。

三个故障共享模拟器、天气和运行时段，不能作为三个独立真实实验批次进行显著性宣称，也不把每天占用期拆成独立故障。事件边界来自官方故障注入，不代表所有变量在非占用时都保持可见异常。后验正常/故障同天气配对显示：风阀和风管故障非占用时的平均流量差仅约0.000091/0.001008 kg/s、静压差约0.0332/0.0306 Pa，而占用期差异更大。这只是可观测性说明，未将同时刻健康副本输入模型或选阈值；占用子组覆盖单独保留在CSV。

G36能支撑这个有界仿真试验；不能补足真实可信运行条件、正常切换及独立持续故障的配对证据。FIT正常支持很有限，当前结果不能区分所有可能的模型/正常支持域因素；可以确定的是：本配置没有把训练收益泛化到正常SELECT，更没有建立误报受控的持续检测增量。
