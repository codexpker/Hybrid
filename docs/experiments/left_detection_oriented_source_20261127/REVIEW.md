# 检测导向源训练的差异与可行性审查

**决定：在第一阶段停止，不启动 M1／M2 完整训练。** 本轮能够提出一个可检验的 LEFT 开发问题：对同一批代理异常，把源排序监督移到短程混合重放之后，是否比更新前监督更能改善真实目标的完整 U？但 M2 的核心是已有的「无标签支持更新 → 独立带标签查询排序 → 回传源参数」。现有方案把这一机制应用于完整 LEFT、合成代理配对与项目现有的重放规则，尚无可单独识别的新学习机制。这个判断来自设计和一手文献，尚未测量 M1／M2 的检测效果。起点为 `caac57656fcc8b7818acbfb74080040d815e7444`。

## 与直接相关方法的差异

| 方法 | 已实现的学习机制 | 对本轮设计的含义 |
| --- | --- | --- |
| Finn 等，MAML，ICML 2017 | 对任务内梯度更新求导，以更新后的任务损失学习初始化。 | M2 属于同类展开。区别在于内层是无标签重构与循环损失，外层是代理异常排序，且内层带 Adam 状态和原型 EMA。这些是训练合同的变化，未引入新的元学习规则。 |
| Kumagai 等，AISTATS 2023 | 用可能混入异常的无标签支持集更新线性重构层与逐样本异常属性。用独立有标签查询的平滑成对 AUC 学习共享参数。内层采用交替闭式更新。 | 论文 §3.3、式 (7)–(10)、算法 1 已包含本轮的判别时序和权限结构。M2 换成完整 LEFT 的 Adam 重放和原生分数，并以同背景的 clean／edited 配对代替带标签查询中的全正负交叉配对。平滑排序函数和配对范围的差异未建立新的作用机制。 |

| 项目历史 `intervention_reference` | 在 TimeRadar 原生 V 上使用局部幅值／时移编辑做源配对监督，并比较两类目标干预参考。 | 编辑、配对监督和直接作用于部署分数已有项目先例。历史 U 在目标更新中使用干预损失，本轮完整 U 只使用原生 LEFT 重放。 |

## 固定三臂所检验的目标

令 `z = (θ, k, m, v)` 表示 LEFT 参数（含原型）、课程步、Adam 一阶和二阶矩。对固定支持批次 `S_j = [16 个代理目标数值窗口, 8 个 TEP 正常窗口, 8 个 SMD 正常窗口]`，记原生状态更新为

```text
z_0 = (θ, k_source, 0, 0)        # 每个内层任务使用 fresh Adam
z_j = U_LEFT(z_{j−1}, S_j)         # 原生训练前向＋显式 EMA＋同一步 Adam
F_5(z_0; S) = z_5

s_θ(X)[j] = mean_c(LEFT_native_infer_θ(X)[j, c])
d(z, X, E) = mean_{j ∈ E}(s_θ(X_edited)[j] − s_θ(X_clean)[j])
R(z; Q) = mean_{(X, E) ∈ Q} log(1 + exp(−d(z, X, E)))

M0: J = L_LEFT,normal
M1: J = L_LEFT,normal + λ R(z_0; Q)
M2: J = L_LEFT,normal + λ R(F_5(z_0; S); Q)
```

这里 `E` 仅表示源代理编辑的预定时间支持。对比使用同一时间位置的原生分数，编辑时间与通道标记不进入部署读出。上式明确本轮 pairwise 排序的一个直接实例，未执行或选定训练系数。源普通损失与外层配对面板应在 M1／M2 共享。M1 同样执行五步数值内层并丢弃其结果。即使窗口曝光和更新次数一致，M2 还需保留反向图并做高阶求导，实测算力不能按 M1 的内层前向轨迹估算。

M1 即使能使初态的代理排序变好，也没有评估重放会保留还是抹去这项分数差。M2 的外层目标能显式度量五步后的分数差，元梯度还包含 `D F_5` 对源参数的依赖。这为比较训练时点提供了理由。它仍受代理编辑代表性、源任务覆盖和短程更新的限制。M2 超过 M0 而未超过 M1 时，两臂共有的判别监督足以解释增量。

数据权限按提出的实验定义。源端只使用 TEP FaultFree 与 SMD 正常资产，排除 PSM、SWaT 及第一篇数据。正常 SOURCE SELECT 单列。支持与查询按原始记录的实际取值足迹隔离，位移供体的读取区间计入足迹，重放的正常槽也受支持侧隔离约束。编辑标记只供外层查询目标使用。目标 U 只接收固定 U-FIT 数组与正常重放。模型及设置封存后，真实 QUERY 标签只交评价器。冻结 Z 与完整 U 均用原生 LEFT 分数。 [已有源与目标角色](../left_multisource_20261126/RESULTS.md)

## 五步与原生部署 U 的一致性范围

- 现有 U 为 W192、每批 32 窗口、16 目标＋16 正常源（TEP／SMD 各 8）的 fresh Adam，学习率为 `1e-4`，执行 2,000 次更新。原生训练前向推进课程一次，按重构、关联与置信度筛选做显式 EMA，之后 Adam 对原型和其他参与优化的参数做一次更新。两域原源 checkpoint 的课程步均为 4,000。 [训练实现](../../../src/hybrid_tsad/left_multisource.py) · [原型读前快照](../../../src/hybrid_tsad/left_decoder_context.py)
- 五步能复现给定批次上的**前五次数值更新**。要验证这一点，需逐步对比原生和函数式实现的损失、参数、原型、Adam 矩及计数，并保留原生随机性、训练模式和预 EMA 快照。朴素使用 `functional_call` 不能自动为原生 `no_grad` 下的 `.data` EMA 写入建立正确的梯度图。固定筛选分支时，若入选原型槽满足 `P_ema = μP + (1−μ) stopgrad(z̄)`，前向值与关于旧原型的局部导数都需要核对。分位数门槛和硬分配的切换处还存在分段行为。若对 EMA 转移或 Adam 状态截断，应明确记录截断位置，不能声称对完整状态求导。
- 原生 `infer` 带 `no_grad`。用作查询损失时应在 eval 状态下调用同一 `_forward` 和 `_ms_anomaly_score`，保持可导并核对数值及状态不变。真实部署继续调用原生 `infer`，按通道均值和 W192 非重叠窗读出，分数在所属窗末可用。 [原生评分接线](../../../src/hybrid_tsad/left_multisource_eval.py)
- 五步仅覆盖真实 U 的 0.25%。即使共享数值规则，代理任务上的 80 次目标窗口呈现也无法验证真实目标的 32,000 次窗口呈现及长期 Adam、EMA 演化。五步高阶图在实批次下是否数值稳定、可放入 A40 及满足 8 A40·小时，均尚未验证。历史一阶速度只适用于基线，不能替代本轮实测。
