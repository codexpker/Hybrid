# Fixed official Time-RCD inference

Official source: `thu-sail-lab/Time-RCD` commit `b031773e323bc0e6c9dcd8c9119b800ec4d70f8c` (Apache-2.0). The original Python source and model/head are unchanged. Official HF multivariate checkpoint revision `0880420070a524efe14d7e163b34dcca90d2be1b`, file `best_model/pretrain_checkpoint_best_multi.pth`, 444841116 bytes, SHA256 `a497ac910f24f8fb347d690a21b60d74bc04785ebc777880553c158dea4434d0`. The required checkpoint was downloaded from the mirror documented by the official README and checked against the official LFS identity. Source/weights remain outside Git.

Both permissions use the original 5000-window / batch-one core and original channel-mean two-class anomaly head, with zero optimization steps. `A_official_role` retains exact API float64 whole-role population normalization (zero std becomes 1e-8). It uses the complete CAL or QUERY role independently, so its normalization sees later points in that role. `B_fit_only` uses fixed raw FIT mean and population safe std once and bypasses the API role-normalization dataset, preserving the same forward/head. It is a changed normalization permission, not exact official preprocessing. Both use offline complete windows.

The raw binding contains 29 records (PSM plus SMD28). CAL and QUERY are never concatenated. Real tail points are retained and repeated padding predictions are excluded. The cached `score` equals official class-one softmax probability. Original `head_logits` (two classes after channel mean), their class difference `logit`, indices, window ends and validity/padding metadata are archived. Scores are never replaced by logits. For A, `available_index == max_input_index` includes the full role statistics dependency; for B it equals the model window end. `window_end_index` separately records the model context. No online claim is made.

Shared modules: `hybrid_tsad.timercd_fixed`, `timercd_fixed_runner`, `timercd_fixed_queue`. Immutable runtime/config SHA manifests and per-process start/OS, input and checkpoint receipts accompany outputs. Each GPU process has a 30 GiB memory cap; free devices only; no external process is displaced. Queue parity executes the actual official API on fixed first-5017 FIT observations (PSM and SMD1-1), then the authorized 58 role-pair jobs produce 116 banks. Labels are opened only by the separate CPU consumer after the global seal and local mirror.

The first real CPU check loaded the official checkpoint through its strict original loader and verified bitexact native-API probability and class difference on 33x2 synthetic observations. This is an implementation witness, not benchmark efficacy. Full FIT parity and benchmark completion require their actual terminal receipts.
