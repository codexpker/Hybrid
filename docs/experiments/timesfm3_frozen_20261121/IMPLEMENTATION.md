The wrapper calls the unmodified official TimesFM3Forecaster. A point t uses only SOURCEFIT-standardized x[t-512:t], transposed as[C,512]. The API receives independent samples as a list of these multivariate matrices, internally[B,C,512], never variables as independent samples. Official internal normalization/inverse, joint variate attention, stitching, detrending and iterative CPM/RevIN remain intact. `use_znorm=False` prevents extra wrapper normalization. The API defaults remain symmetric averaging=False, positivity=False, sorted quantiles=True and padding_mode=none. Every origin requests horizon1 independently; internal rounding to output patch64 does not reuse those other outputs at later origins.

The score is the channel mean squared difference between the official sorted median(index4 of nine quantiles) and the current arrived normalized observation. Saved FP32 prediction/actual arrays are promoted to FP64 before subtraction/square/meanC. Current values are indexed only after forecasts return. Full quantile outputs are retained for provenance, not extra score selection. There is no anomaly head, source training, adaptation, score fusion, threshold search or sparse-query sampling.

Original SOURCEFIT scaler, roles,512 CAL indexes and dense query axes are reused bytewise or through explicit source-TASK hashes. The new wrapper task also preserves an exact ORIGINAL_TASK copy. SWaT uses31 channels and336321 QUERY points; PSM uses25 channels and64728 QUERY points. CAL and QUERY are independent calls with histories wholly inside their legal role. Source-only fixtures verify exact median/quantile identity, finite values, no current/future input, single-vs-batch/order consistency and immutable model/RNG.

Resource timeout is fixed from source speed as max(900s,3*shard_prediction_seconds+180s). The executed scorer snapshot is immutable; the future public entry differs only by explicit original-TASK copying and source-profile-derived resource timeouts, not scientific functions.

Final banks preserve prediction_normalized, quantiles_normalized, actual_normalized, actual_raw, squared_error_per_channel, canonical_score, exact original indices and strict past512 footprint.
