# G36固定条件参照与响应反馈匹配验证：限定NO-GO

## 结论

两臂各3000步训练、合法CAL及全部QUERY读出均完成，固定配方停止。无反馈臂的正常SELECT平均energy优于自身初始化，但明显不及有反馈臂；更重要的是，两臂生成的正常分布对正常SELECT/CAL的尾部位置失配，有限探针分数大量达到上界。原定CAL阈值落在分数上界，故严格大于阈值的报警规则无法触发：三种故障均漏检。**0正常误报是没有报警的结果，不是成功保护正常工况。**

没有修改阈值、MC探针数、检查点、网络、历史、损失或评分来补救。不进入U/F，不自动生成替代候选；不把本结果扩大为所有条件信息无效、或所有持续故障均不可观测。

训练前冻结的有限正常门槛是context_only选中非0步且SELECT严格优于自身初始化。本轮因此依约进入固定读出；该门槛仅证明平均学习目标跨到一个正常SELECT日有所改善，**不是正常分布、尾部校准或条件充分性已经成立**。没有追看未选中权重QUERY。

## 正常分布与有限评分失效位置

固定score为 `-log((1+normal_tail_count)/256)`，最大float32值5.5451774597。两臂CAL q99均恰为此上界；strict >不可能触发。

| 正常角色 | 无反馈：探针tail_count=0 | 有反馈：探针tail_count=0 |
|---|---:|---:|
| SELECT | 237/237（100%） | 199/237（83.966%） |
| CAL | 237/237（100%） | 83/237（35.021%） |
| 正常QUERY | 6549/7954（82.336%） | 1558/7954（19.588%） |

例如CAL观测到正常参考的平均距离，无反馈为1.3362、模型正常探针到参考仅0.3539；有反馈分别0.5018和0.2680。该现象与生成分布不能覆盖所遇正常响应一致，但不足以仅凭这些均值区分位置偏差、离散度不足和条件支持不足各占多少。

有限探针截断确实造成严重并列与无法报警，是本固定评分链的实际限制；同时，失配在正常SELECT/CAL已经存在，不能仅解释成未来QUERY的CAL迁移，也不能宣称增加探针即可建立检测贡献。本轮不另算连续energy替代AP、不改变离散分数、不提出新校准补丁。

有反馈在冷却阀配对AP0.835593/ROC0.902409，保留这项相对排序信息；其风阀/风管AP0.510814/0.593181。无反馈三者AP0.547374/0.503635/0.520060。禁止响应历史没有换来额外故障特异性，当前新判据也没有把已有相对信息转成可用持续报警。

## 科研取舍

本轮不支持“仅由现有合法条件驱动、禁止响应反馈”的参照方案成为Hybrid方法增量。可确认的是有限正常平均loss学习，而非可靠正常分布。实际过去响应对正常拟合和部分异常排序仍有价值；不能以防止异常进入历史为理由直接删除它并声称得到更可信参照。

证据限定于该生成学习、距离及tail判据的组合，seed2025与G36固定五周仿真；不能分离所有模型容量、缺失条件和短FIT支持因素，也不能给条件信息本身作普遍NO-GO。原真实独立确认、噪声/容差、工况条件充分性限制均保留。本候选到此停止，不扩训练/阈值/生成器，不将失败写成污染鲁棒或Stage2-U证据。
