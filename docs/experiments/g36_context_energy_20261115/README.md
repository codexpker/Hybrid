# G36 条件驱动正常分布：一次固定反馈消融

用户批准执行的唯一配对：`context_only` 与 `response_feedback`。前者将严格过去四响应输入槽置零；其余模型初态、正常 FIT 抽样、优化器、预算、SELECT 与评分相同。目标不是再次调整旧 flow 或其阈值。

## 冻结定义

- 沿用 G36-5wk 四 CSV、四响应、五历史条件、全部三个故障与全部原 QUERY 点。原数据 manifest/scaler/FIT_PLAN 不改。
- 48 点过去输入到随后 4 点响应；第 t 点到达才评分。沿用旧 TCN 的有效感受野 31 点，不冒称实际使用全部 48 点。
- 两层 64 隐单元生成器，16 维高斯噪声，输出 4×4 正常响应。没有查询状态更新；真实健康 QUERY 副本不进入检测器。
- 距离为 FIT 标准化响应的 L2/sqrt(16)，加保留 DC 的正交 rFFT 对数幅值 L2/sqrt(12)。不逐窗去均值。确定性变换不是新增传感信息，也不单独证明频域贡献。
- Energy loss = E d(y,g) - 0.5 E d(g,g')。训练每样本 16 独立样本对，SELECT 64 固定对。属于成熟 proper scoring 思想，不称原创公式；来源 Gneiting & Raftery, JASA 2007, DOI 10.1198/016214506000001437, §4.3。自有 PyTorch 实现，不冒称官方代码复现。
- 原 seed2025、3000 updates、batch64、Adam1e-4、clip1，SELECT 第0及每300步取最小、同值较早。选择目标相同，不用检测标签。
- 先完成两臂训练。**context_only 必须选择非0步且正常 SELECT energy 严格低于自身初始化，才开启本轮 CAL/QUERY 读出。** 这是有限正常跨日学习门槛，不是误报认证；不通过则停止，不补看其他 checkpoint 的 QUERY。
- 评分使用 64 独立正常参考对与 255 独立正常探针；三个固定噪声银行跨样本、run、两臂共享。p=(1+#正常探针energy>=观测energy)/256，s=-log(p)。共同 energy 常数在比较中抵消，原始 energy 仍保存。
- 离散分数最大 log(256)。若合法 CAL q99 落到该上界，严格大于阈值会无报警；必须原样报告，不能扩大探针数或更改阈值补救。
- CAL 沿旧 q99/higher/strict >，C3 第三点起生效，不回填。健康/故障配对仅评价后使用；模式不一致全部保留单列。

## 对比与边界

旧 LEFT、条件 Ridge、历史 Ridge 原始银行直接复用；同轴重新汇表不重跑训练或推理。LEFT 使用到达窗口原生重构，Ridge 与新模型是严格过去预测，训练任务不同须披露。

只评估该固定配方的正常跨日泛化、故障特异持续覆盖与误报。三种相关仿真情景不是三个真实独立设备；CAL 仅一天237重叠点，不能认证总体1%误报率。无重复健康轨迹/可信外部全部状态，现有条件充分性仍待检验。结果不证明物理因果、污染鲁棒性或Stage2-U/F有效。

本轮停止条件：正常 SELECT 无学习增益，或固定评价未提供误报可接受的实际故障增量。不换种子、历史长度、距离、MC数量、阈值或评分。不自动扩展候选。
