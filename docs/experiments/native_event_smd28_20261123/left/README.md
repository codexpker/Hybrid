# LEFT external benchmark on 28 SMD machines

Each machine uses its own random initialization (seed 2025), all 38 channels, published normal train segment and untouched test segment. The evaluation keeps machine boundaries. The author SMD configuration and training loop at revision 3fadb4811797075e233076b9faceb0d8ec59b697 are used separately on each machine. For this machine-wise benchmark the physical record loader supplies the original machine-specific numeric arrays; the learner has no access to test labels or values during fitting or selection. [Fixed upstream SMD configuration](https://github.com/DezhengWang/Left/tree/3fadb4811797075e233076b9faceb0d8ec59b697/configs/SMD).

The scaler uses the complete published normal training segment. Gradient updates use its first 80%, with the last 20% used for normal validation. Windows have length 192, training stride 1, validation stride 192, test stride 192, batch 128. Adam uses lr 1e-4 with the author's type1 decay, 20-epoch maximum, patience 3. The official training loop restores the validation-selected state dict. Its Python step after training and selected-checkpoint step are both recorded. The existing three-machine experiments used separate FIT/SELECT/CAL roles and FIT-only scaling and remain a separate historical comparison.

Scores come directly from the official infer routine. Every complete test window contributes all 192 per-position scores (float32 mean over the 38 output channels); each is available at the corresponding window end. The native table covers [0, 192 floor(N/192)) separately on each machine. The common-axis ranking table independently crops the same banks to the intersection with causal TimeRadar scores. Both areas under the volume surfaces use the same pinned RangeAUC_volume_opt implementation with windowSize=100 and thre=250. AP is average precision.

The project's standard CAL lies within LEFT's validation and scaler data. An independent CAL operating point for this native-trained reference is unavailable. Its thresholded stream and event-level results against the candidate's independent CAL are consequently NA.

Across all 28 machines, native readout scored 705,984 of 708,420 test points. The entity-macro AP / ROC-AUC / VUS-PR / VUS-ROC are 0.497514 / 0.878682 / 0.541517 / 0.918616. The median respective entity values are 0.459777 / 0.877672 / 0.470190 / 0.933970. Fifteen machines reached the 20-epoch cap, ten selected epoch 20. The remaining checkpoints were selected between epochs 1 and 19. Total measured occupied GPU time was 1.6455 A40-hours during initialization, source-data handling, training and validation, and 0.0032 A40-hours for native inference and score-bank writing.
