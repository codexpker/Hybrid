# Static proxy ranking for multi-source LEFT

This paired development experiment starts from the two archived dimension-specific LEFT source checkpoints and uses only PSM and SWaT as target folds. M0 is the archived source and replay reference. C continues the complete native normal loss. M1 adds proxy ranking on the native deployed score. The study tests usefulness under the existing complete U program. Its literature positioning is in the [preceding review](../left_detection_oriented_source_20261127/REVIEW.md).

## Training and information permissions

- Native LEFT uses W192, 25 PSM or 31 SWaT variables, existing pre-EMA prototype reads, and the original loss, curriculum, EMA, and inference components. Both new source arms use 2,000 fresh Adam updates at 1e-4, 32 normal windows per update, 16 from each of TEP FaultFree and SMD FIT. The existing record and channel sampling rules apply. The normal sequence and seed 2025 are paired within target fold. The source endpoint is always step 2,000 of continuation. The fixed 1,024-window normal SOURCE SELECT panel is observed at update 0 and then every 400 updates.
- Each M1 update makes one clean/edited pair from each of the 32 sampled normal windows. Each source contributes eight amplitude and eight shift pairs. The observed support is 20 consecutive positions starting uniformly at integer positions 6 through 166 inclusive. Each edit samples ceiling(C/4) distinct channels. Both types use the existing squared-sine envelope. Amplitudes have random sign and magnitude Uniform(1,2) in the source scaler units. Shifts are drawn from ±3 and ±6, entirely within the same sampled W192 window, with no wrap. The normal, scale and editing NumPy streams have distinct SeedSequence purposes 1, 2 and 3 under [2025, 20261127, purpose]. The edited input is an artificial construct and the normal stream and observed support supply all supervision.
- Training minimizes the native LEFT loss plus 0.1 times the mean, over pairs and support positions, of `softplus(1 + asinh(s(clean)/a) - asinh(s(edited)/a))`. The score `s` averages the native point score across channels. Scale `a` is the corresponding M0 median over all channel-averaged point scores from 64 fixed normal FIT windows, floored at 1e-6. Each step runs the normal train forward and its backward first. The pair path reads the post-EMA state before Adam, takes an eval-mode native-score forward and backward inside an isolated Torch RNG scope, then one Adam update applies the accumulated gradients. The 32 clean and 32 edited score presentations per step and their compute are additional to M1's matched normal budget. C runs no pair path.
- Each frozen Z checkpoint receives one original-grid QUERY readout, then starts fresh Adam replay U with the unchanged 2,000-update sampler and program. Each U update sees 16 fixed U-FIT target windows and eight normal windows per source. The U learner receives values alone. Neither source training nor U reads target labels, and the learners use no experimental motor data or sealed controlled test bank. Checkpoints and readouts are sealed before opening evaluation labels.

## Evaluation and decision

Apply the prior QUERY masks, PSM test-relative [22656,87744) and SWaT absolute [608535,944856). Reuse the original W192 grid, left boundary handling, and window-end availability. Both Z and U use the untransformed native score. Compute AP, ROC-AUC, VUS-PR and VUS-ROC. Report M1−C, M1−M0 and each arm's U−Z on the same axis. No new CAL or operating point is selected. The established CAL constraints and prior operating results retain their own scope.

Continuation requires one domain with M1 U AP at least 0.005 above both comparisons, the other no more than 0.005 below either, positive two-domain mean AP differences against both, and no ROC-AUC or VUS regression exceeding 0.01 against either in either domain. Local positives with no passing complete U gain or with material metric costs stay local. Absent a net effect under the fixed comparison, end this setting. No new seeds, editing rules, thresholds, target tasks or adaptation variants follow automatically. [Archived M0 scores and costs](../left_multisource_20261126/RESULTS.md)
