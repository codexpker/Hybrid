# Fixed SMD machine-3-2 / machine-3-3 extension

This run adds only seed2025 R and R_target_mean for two preassigned SMD entities, with official frozen initialization, decoder-only AdamW, 2000 endpoint updates and logical batch64 as in the accepted SWaT/PSM experiment. R uses full ten-copy reconstruction MSE; R_target_mean changes only the target half to differentiable mean-copy reconstruction MSE. The source half, masks, optimizer, window grid and official terminal-V scoring remain identical. NoU requires new inference because historical norm1/batched scores are incompatible.

Both entities use original train FIT[0,14221), test U_FIT[0,7901), and test QUERY input[8445,23703), scored[8957,23703). Entity3-2 CAL is train[19505,23702); entity3-3 CAL is train[19506,23703). The original role manifests remain unchanged. Current permission explicitly reuses the old DONOR value fragment as naturally mixed unlabeled U_FIT; no donor label/type is read by training. Source data are nominal native train, not independently certified healthy.

`role_records` binds each permission to its physical entity/train-or-test record, with fragment storage origin. Role is excluded from identity. Mean/std(ddof0, tiny std replaced by1) use only the stored raw float32 FIT fragment, accumulated in float64. Source and target pools contain142 and79 complete non-overlapping100-point windows respectively. The paired PLAN is drawn once by the unchanged seed2025 rule and shared by both arms. All CAL points are selected by fixed linspace512 from the pre-existing legal CAL_arrived_target_original grid; CAL has no independent point labels. QUERY retains the old512 warmup axis even though native inference uses100 points.

All four endpoints freeze before any CAL/QUERY forward. Twelve final banks (noU/R/mean × two entities × two roles) preserve native float32 V, canonical_score=V.float64, terminal ten reconstructions, actual order, current values and true100-point footprint. Every native forward is B1 with norm0, copies10 and isolated CPU/CUDA mask seed84551. Official weights and raw arrays remain outside public Git. Evaluation-only full test-label txt bindings are stored separately and never opened by training/scoring. Labels are opened only after all twelve banks are sealed.
