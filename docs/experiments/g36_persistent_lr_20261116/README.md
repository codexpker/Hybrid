# G36：条件正常状态与持续偏离的固定匹配验证

用户2026-11-16批准，非旧energy/尾概率配方恢复。不生成新变体、不改原数据或历史结果。旧Hybrid及所有限定NO-GO保留。

## 唯一模型与数学定义

沿用G36四响应、五条件、52点完整可见输入和原首评分索引。为保证每个响应块的条件都严格在其之前，响应使用输入index4:52（12个4×4块），对应条件为index0:48（12个4×5块）。因此响应状态窗口包含44个过去响应点和4个当前已到达点，最早4个输入点仅供条件；不虚称48个过去响应点均用于过滤。模型无健康QUERY副本、无跨角色隐状态或QUERY参数更新。

z_b=g_theta(Y_b)为4层时域/Haar共轭可逆耦合映射，hidden32，初始identity，不逐窗去均值，保留水平/DC。条件GRU20→32按块输入过去4×5条件，不输入响应。状态8维，观测16维：

`x_b=A x_(b-1)+B h_b+w_b; z_b=C x_b+D h_b+v_b`。

A的Frobenius范数约束≤.98，Q/R为`.001+softplus`正对角；初态均值/正对角协方差可学习。精确Kalman递推边缘化状态，优化正常轨迹NLL减g的Jacobian/192，梯度穿过全部学习路径。Kalman使用float64避免数值失真，映射float32；当前响应只在到达后进入本块innovation/update，预测在更新之前。

H0为上述正常模型；H1仅增加每个窗口固定的潜在偏离delta：

`z_b=C x_b+D h_b+delta+v_b; delta~N(0,Lambda)`。

delta与初始正常状态独立，以16维常量状态精确边缘化（转移I/过程噪声0）。H0/H1共享全部正常theta，均为归一化密度；不是给残差优化delta后忽略复杂度。Lambda=所选g对正常FIT按原始role起点非重叠4点块编码的逐坐标总体方差+1e-4，取对角；在CAL/QUERY前冻结，各模型同规则。不搜索倍数、故障方向、偏离时间或先验。

唯一Hybrid分数`log p_H1(z_1:12|h)-log p_H0(z_1:12|h)`，映射Jacobian抵消，不裁剪、不使用探针、无固定评分上界。固定12块窗口每个原索引均独立计算，不递归积累报警，不跨断点承接状态。当前窗口是否需要持续偏离解释是统计命题，不认证物理故障或可信指令。

## 匹配实验与继续条件

- 两训练臂：full（学习g），linear（g=identity）。状态/条件公共参数初始逐tensor一致；线性对照缺少可训练g，不宣称等有效容量。相同seed2025、原FIT_PLAN、3000updates/B64/Adam1e-4/clip1、正常SELECT0及每300步、最小同值较早。仅训练H0，不合成故障标签或训练H1。
- 三主方法：full_LR、同一full权重的H0_NLL（完整window NLL含Jac/192）、linear_LR。消融无新增训练。旧LEFT/Ridge原银行直接复用，同轴评价、输入任务差异披露。
- 正常门槛：full正常SELECT选中非0步且比自身初态NLL严格改善，才继续本轮固定CAL/QUERY。正常mean损失改善不等于分布校准或误报保证。选中step0则停止，不救援末次权重。
- 数学可辨识门槛：同一条件轨迹下H0/H1联合协方差应满足Sigma1=Sigma0+U Lambda U^T，差非零且PSD，Lambda=0两密度相同；直接联合高斯与Kalman应一致。此为所设统计假设不退化的证据，不等同真实正常/故障已经可分。正常初态变化与delta重叠时检出仍可能很弱。
- 两个门槛均通过后，在原SELECT/CAL和四完整QUERY上读出两logp、Jac、LR/NLL及必要预测/协方差原件；先封存分数再打开评价标签。CAL沿原q99/higher/strict>；原三连从第三点起，不回填。
- 健康副本仅做事后故障独有/共同报警四象限；原模式不一致区间保留单列，三故障均保留。不得把三相关仿真情景当三个真实独立运行。

## 科研边界与停止

正常切换保护仅在正常模型能够解释已观察条件/状态演化时可能成立。条件遗漏或模型误差可能误触发H1；若正常变化与故障可由相同状态变化解释，则此统计设计不能确保识别。模型自有高似然不认证物理正常。

无独立增量则停止整套配方，不调A界、latent维数、窗口、先验、阈值、训练或读出。不会以零误报但零覆盖作成功，也不凭高覆盖忽略正常误报。当前仅仿真机制验证，不证明新U/F、多源预训或污染鲁棒。

思想来源为DeepState（NeurIPS2018，§3–4，条件驱动状态空间边缘似然）与经典动态故障的似然比较（Willsky, Automatica1976）。自有实现，不称上述方法官方复现；状态空间、Kalman或Bayes因子本身均非项目原创。可能贡献只在本完整机制相对同权重正常判据和线性动态强对照的实测增量。没有将LEFT改名为Hybrid。
