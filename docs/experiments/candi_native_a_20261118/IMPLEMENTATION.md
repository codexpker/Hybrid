# Complete CANDI under the fixed natural-mixture task

External method: [kimanki/CANDI](https://github.com/kimanki/CANDI/tree/28c9679e503832f59e351208cde63657fcb51cad), commit `28c9679e503832f59e351208cde63657fcb51cad`. This imports the complete official MLP, FPM, input/output SANA and window reconstruction objective. It is not a Hybrid module. The external checkout has a Modified MIT Non-Commercial-with-Permission license and is not vendored or relicensed here.

Seed2025, SWaT31 and PSM25 use the already fixed natural-mixture A roles and QUERY axes. Source FIT alone trains the native MLP and fits its StandardScaler. Normal source SELECT alone supplies validation/checkpoint selection and the complete FPM reference pool. No compatible pretrained checkpoint was found for these two channel definitions; the earlier SMD smoke checkpoint is not substituted.

The main official configuration fixes window10, stride1, latent128, source batch256, Adam1e-4, 30 epochs with its cosine/warmup schedule and normal validation every5 epochs/final epoch. SWaT uses `scripts/SWaT/SWaT_alpha_5.0.sh`: alpha5%, SGD adaptation lr.03, five steps and gate.5. PSM has no dedicated main configuration and uses the main defaults: alpha.5%, SGD lr1e-4, one step and gate0. No defaults from the distinct TSB-AD wrapper are mixed in. The source trainer's actual code, including its absence of a gradient-clipping call, takes precedence over unused config flags or paper/code discrepancies.

After selecting the source checkpoint, CANDI consumes each legal U-FIT sliding window in chronological order once, maintaining the original FPM hard/moderate buffers and minimum16 rule. Actual accepted-window and optimizer counts are recorded, not matched artificially to LEFT's2000 updates. The backbone is frozen during this phase while SANA is trainable. After U-FIT the entire model is frozen for separate CAL/QUERY readouts. This is a project U-FIT-adapt/QUERY-freeze protocol, not the author's continuously adapting test-stream experiment.

Only label-counting statements are removed from a runtime AST copy of the official selection function; the learner never receives target labels. Full-reference representation computation is batched by sample. PSM used reference-axis Mahalanobis/min/any chunking and passed its complete-pool numerical and update checks. SWaT's initial reference-axis check failed: the hard-pool distance difference reached0.000988. Before its first U update, the computation was changed to query microbatches with the full reference dimension and original broadcast expression. The checked distances and acceptance masks then matched exactly; selected actual input tensors matched, and five SGD steps on each discarded check copy differed by at most1.19e-7 in parameters. No covariance regularizer, reference truncation or selection-rule change was made. All source SELECT references, covariance/pseudoinverse and thresholds remain. These bounded checks are not an assertion of bitwise equivalence for every possible input.

Two original failures are preserved: SWaT stopped at that pre-U numerical check; PSM stopped after writing complete adapted scores because sequential DataLoader iteration consumed a CPU base-seed RNG draw. Both source trainings and the completed PSM adaptation are retained. SWaT's original SANA initialization was recovered from the fixed source loader RNG trajectory (66 recorded CPU draws); first256 and last175 original normal-reference representations matched bitwise. It then ran only its previously unexecuted U phase. PSM's existing adapted banks are accepted only after complete index/finite/hash checks and fixed first/middle/last batch replays from the same endpoint. Its original CPU RNG side effect remains disclosed. Missing noU readouts and new frozen readouts use an isolated DataLoader generator. The original frozen worker identity and later recovery identities are separate; no historical receipt is rewritten to claim the original guard passed.

The released code's live moderate score predicate is overwritten to `score < source_threshold`, whereas the moderate reference pool remains Q1--Q3. The output SANA correction is subtracted in code. Neither is silently rewritten to match prose. Source FPM percentile thresholds remain distinct from the final project's512 mixed-CAL q99/higher/strict-greater threshold.

Every score is the official MSE over a real10-by-C window, mapped to its actual last observed point, with no padding or window-label broadcasting. SWaT common QUERY is `[608535,944856)`; PSM is `[22656,87744)`. All original CAL512 points retain legal complete inputs. LEFT retains its192-point nonoverlapping full-window retrospective outputs and its existing scaler including source validation; these differences are disclosed rather than treated as an equal-architecture adaptation ablation. PSM's all-attack CAL remains unchanged and does not certify a normal false-alarm rate.

Entry: `python -B -m hybrid_tsad.candi_native_a {prepare,queue,worker} --workspace <workspace> --output <new-result-directory>`. Configs, official file identities, selected weights, scaler, update traces, complete scores, OS exits, device/peak memory and elapsed GPU time are retained outside Git. This command documents the fixed implementation, not permission to repeat successful jobs. Existing LEFT noU/TT-A/R-A seed2025 metrics are reused; no B/C or additional seeds are scheduled.
