# 固定公共 Z 开发比较

本轮使用原型原样推进公共评分。旧合成比较中的匹配残差 AUC 为 0.958333／1.000000，增量的上限只有 0.041667／0。因此旧 +0.05 门槛在这两组不可达，原结果仍为未通过。该判据未能识别确认机制的额外价值，公共 Z 的价值由本轮同轴结果另行判断。 [原型结果](PROBE.md) · [数学定义](PROTOCOL.md)

固定 PSM、SWaT 和全部 SMD28。A/B/C/D 全部复用 e59 各折原生 A 端点、原始 scaler、TEST 评分缓存及 W192 网格。原型使用 H256＋W192、每窗三块 W64。共同轴固定为 e59 原生分数的完整合法 TEST 轴。相对 TEST 角色起点，首个窗口从 576 开始，尾部舍去不足 W192 的点。对候选而言 384 起点已有合法历史，该单窗在既定原生缓存轴外。PSM 和 SWaT 保留其中的全部窗口，SMD 保留固定 28 台的各自轴并做等权实体宏平均。所有分数在当前窗末点可用。旧 CAL 与原生评分条件不兼容，本轮操作点统一 NA。

| 臂 | 唯一定义 |
|---|---|
| A | 不重算的原生 LEFT 点分数 |
| B | 原型相同正常滞后、历史边、拟合和归约的绝对关系残差，照常用经验尾秩与原生尾秩取最大 |
| C | 同一替代滞后侦测。保留各半对该半最优合法备选、拟合半误差低于正常滞后条件，以及另一半的误差收益。移除“两半选择同一个替代滞后”和“两方向均有正收益”的确认，取两方向中合格的最大正 held-out 收益。只用这一个 C 定义 |
| D | 原型确认时延。要求两半选择同一个备选，取两方向正收益的较小者。其余与 C 相同 |

C、D 同一次关系计算共享输入、历史边、滤波、合格候选集合、截距／增益、误差和方差归一。C 取最大是单向证据足以成立的对应归约，D 取最小要求双方都支持。同一块所有臂仍按原型取最大边。归一前应有 C≥D。B/C/D 共享原生尾秩参考、同一批 1,024 个冻结正常 SOURCE SELECT 窗口，以及同一个经验尾秩算子和 max 融合。关系边的数值参考分别取对应统计量在这同一正常源集合上的分布，不筛去零值。源协议未生成兼容的逐点 SELECT 原生分数时，仅在这一小面板补冻结 LEFT 前向。测试不补模型前向。

报告共享弃权（块中没有可评估的正常参考边），替代不可比较（没有合格替代模板的块），以及各统计量非零和关系尾秩严格提高原生尾秩的比例。分母为轴内窗口或块，明确标注。仅在三个数据域全部四臂评分封存后打开 TEST 标签。沿用库中的 AP、ROC-AUC、VUS-PR、VUS-ROC。以原生 A 缓存和其已核验同轴指标交叉核对。

本轮在看 TEST 指标前固定决策。实用收益要求 D 在同一域的 AP 相对 A、B 各至少 +0.005，且在其他域相对两者均不下降超过 0.005。独立机制要求至少一个满足实用收益的域同时 D−C≥0.005，且其他域 D−C 不低于 −0.005。关闭实用收益未达到的候选；实用收益达到而机制条件未达到时，保留观察并取消确认机制核心贡献表述。只有二者均满足才保留为后续候选。保留全部四指标、逐机方向及操作代价。该开发判断不替代独立重复，也不以补新合成银行作为本轮前置。
