# 公共 Z 冻结开发验证

四臂、定标、共同轴和继续判据在读取本轮 TEST 指标前封存于 `fa46e566c9fce5bb3f5a488d8af09c53c3f7f284`。A 为原生 LEFT，B 为原生＋匹配关系残差，C 为原生＋无确认的替代滞后证据，D 为原生＋完整确认时延。三条关系臂共享历史、候选集合、方向拟合误差和尾秩规则。C 仅取消一致候选和双向正收益要求。对旧缓存内 144 个块的核对确认，新增 C 前后的 B、D 数值完全相同。 [冻结协议](PUBLIC_Z_PROTOCOL.md)

复现时先在允许的设备上运行 `seal`；只有全 30 个实体的全局封存回执存在时才可运行 `metrics`。

```bash
PYTHONPATH=src python scripts/evaluate_confirmed_delay_z.py WORKSPACE OUTPUT seal
CUDA_VISIBLE_DEVICES="" PYTHONPATH=src python scripts/evaluate_confirmed_delay_z.py WORKSPACE OUTPUT metrics --workers 6
```

## 成本、取舍与归档

三折正常 SOURCE SELECT 各 1,024 窗，仅补了共 96 次原生 LEFT 批前向，共 1.54 秒同步计时。源 CPU 关系计算 30.73 秒，源定标循环及落盘合计 32.76 秒。TEST 的 6,387 窗均复用原生缓存，共新增 57.20 秒 CPU 关系计算和 1.13 秒组合计算，约 8.96 毫秒／窗的关系计算。TEST 模型前向及训练更新均为零。成功的指标阶段另计 84.84 秒墙钟。这些是分阶段计时，源模型装载、资产读取和归档等外围开销不全在计时之内。首轮 CPU 指标核对因类型错误退出，修正后仅重算指标。 [实测成本](public_z/costs.csv)

30 个实体的原生分数和索引与缓存逐点一致。在独立 CPU 核对中，3,678,912 个联合分数由封存的关系值及定标参考精确复算。120 行中 AP／ROC-AUC 与独立排序实现最大差 2.22e−16。VUS 继续用既有实现，宏平均及配对归约已复算。原始分数和源定标 NPZ 保留在研究服务器 `results/left_confirmed_delay_public_z_20261127_v1`，可由 [全局封存](public_z/SCORE_SEAL.json) 和各实体回执定位。 [读出复核](public_z/READOUT_CHECK.json)

**关闭固定确认时延候选。** 三域中没有一域的 D 同时超出原生与匹配残差的预定实用收益。PSM 上的确认相对无确认正项是这一评分条件下的局部机制证据，完整方法在公共 TEST 上的劣化决定了本轮关闭。SWaT 和 SMD 的结果也不支持把确认认定为一般核心贡献。本轮结束在 Z。 [固定判据的机器可读决定](public_z/DECISION.json)
