# 原型验收与决定

本次从封存点 `3a849977f7471a62ad679cf4022746e9764b0da0` 出发。H256＋W192 原型复用完整多源 LEFT 的分数，新增的是双半块交叉确认的时延证据。数学目标、正常历史的辨识条件、Z／U／F 规则和继续门槛在 [方案与验证表](PROTOCOL.md)。

## 跑通的程序

从两个已经封存的合成银行各读取 64 条独立耦合 AR 记录。输入、旧 LEFT 评分缓存的 SHA-256 及所用记录索引均保留在 [回执](receipt.json) 中。当前统计量在历史上重新拟合，共恢复 832／832 条已知生成关系。配对干预共用同一个未编辑历史。编译及 3 项聚焦 CPU 测试通过，覆盖固定历史、仅改变滞后、块内截距／增益不变量、较晚样本隔离、无可辨识关系时的自然弃权，以及可能出现“高残差、无可复核新时延”的数据流例子。

运行命令在已有 Linux 研究环境下为

```bash
cd /home/a312/tsad_research
CUDA_VISIBLE_DEVICES="" OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 \
    PYTHONPATH=/path/to/hybrid_ad/src \
    envs/timeradar/bin/python /path/to/hybrid_ad/scripts/probe_confirmed_delay.py \
    /home/a312/tsad_research tmp/confirmed_delay_probe_new
```

探针全程 CPU，使用零次新增模型前向、零次训练更新。远程命令实测墙钟约 8.5 秒，包括启动和读取。当前不读取公开 TEST 标签。

## 取舍

任务正对照通过，结构识别和组合接口通过。双半块复核相比最强的匹配机制对照未达到事前要求的 0.05 偏好 AUC 增量。**本轮停在原型阶段**。这项探针的校准只用于组合接口和继续判据的前置检查。真正的公开 Z 比较及按正常 SOURCE SELECT 校准的机制实验均未执行，因此本轮没有新的真实数据 AP 或部署代价结论。

具体缺口是现有银行缺少**同等正常参考残差下、能被同一跨变量驱动的替代滞后解释和不能被解释**的对照。当前数据既不能支持该判据有独立价值，也无法检验双半块复核能否在真实过程降低误报。将来如果有预先固定的独立证据能够区分这两种情形，可按 [验证表](PROTOCOL.md#最小决定性实验) 同时审查完整公开检测收益与机制收益。普通条件残差保留为必要对照。

后续边界说明。部署接口的匹配残差 AUC 为 0.958333／1.000000，+0.05 的最大可能增量上限实际为 0.041667／0，旧标准在这两组不可达。原结果仍为未通过。该结果限定合成银行对独立确认价值的检验能力，公共检测表现另由 [四臂冻结协议](PUBLIC_Z_PROTOCOL.md) 判断。
