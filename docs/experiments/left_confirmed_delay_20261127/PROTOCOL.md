# 多源 LEFT 与双半块确认的时延证据

## 可检验的缺陷

旧合成银行的主驱动时延从 4 点移到 16 点。PSM／SWaT 宽度上，旧联合关系模型对“延迟编辑 vs 等能量幅值编辑”的核心区 ROC-AUC 为 0.296／0.480，简单历史相关为 0.555／0.533。留出系列在 PSM 正常 N、SMD 冻结 Z 相对各自内部对照有正项，同时保留完整检测器相对匹配原生 LEFT 的差距，以及同权重历史替换和受控机制的阴性证据。这些结果支持一个较窄的问题：现行分数可能检测到一般偏离，却没有足够证据区分“相同驱动在别的延迟上仍能解释响应”和“响应仅发生幅值或水平变化”。现有结果不能确定瓶颈一定来自池化、网络或训练目标，也不能证明真实公开标签中有足够多这种事件。 [旧关系结果](../left_history_relation_20261126/RESULTS.md) · [冻结历史及留出结果](../left_holdout_history_20261127/RESULTS.md)

对一条可用的统计关系 \(i\to j\)，正常假设是经过同一固定滤波后，\(z_{t,j}=c+a\,s z_{t-d_0,i}+\epsilon_t\)，其中符号 \(s\) 从过去确定，增益 \(a\ge0\) 和偏置 \(c\) 可以随块改变。目标异常是在同一块大部分时间内持续为 \(d_1\ne d_0\)，并保留驱动、响应符号及足够信噪比。偏置变化、正比例缩放以及相同方向的同步时间平移是对照。先假设局部响应近似单驱动、单滞后。同一可见块若可被两个延迟经仿射变换同时解释，数据无法区分它们。周期信号、恒定驱动、低动态、多驱动、快速切换或历史本身已偏离都可能造成弃权或误判。方向是统计预测方向。

在常系数、同方差且误差与驱动不相关的模型下，投影掉截距后，若当前真实模板是 \(u_1\)，把它误用 \(u_0\) 拟合会增加约 \(a^2\operatorname{Var}(u_1)(1-\operatorname{corr}^2(u_0,u_1))\) 的均方误差。这里使用无符号约束的最优斜率推导，实际的固定符号约束只能使错误模板的误差下界更大。条件限制当两个模板接近共线时应该放弃比较。该式也解释了为何“等能量”并不意味着两个编辑应有相同统计响应。

## 完整候选

1. **输入与母体。** 保留已有多源原生 LEFT 全窗输入 \(X\in\mathbb R^{192\times C}\) 和原生点分数 \(L_t\)。关系计算另读同记录、同角色的前 256 点 \(H\)。按各折已有 FIT 合同标准化，沿用项目源排除设置。在当前窗的末点发布整窗分数。本方法沿用回顾式发表时间，即使关系模板对每个响应点只读取严格较早的驱动观测。256 点只从合法的过去截取，当前值不进入正常关系的选择或验证。
2. **历史学习目标。** 由历史前 128 点的通道 AR(1) 斜率中位数得共同 \(\rho\)，截断到 \([-0.95,0.95]\)，使用 \(z_t=x_t-\rho x_{t-1}\)。对每个响应变量，遍历其他通道和 1–24 点滞后，在原始历史足迹 \([0,128)\) 中最小化带截距的一元线性 MSE，相当于最大化平方相关。用独立原始足迹 \([128,256)\) 验证原参数相对训练均值的预测增益。每半段前 25 点为滤波及滞后预热。验证 \(R^2\ge0.20\) 时保留一条 \((i,j,d_0,s)\)，其中 \(s\) 是历史斜率符号。无合格边时弃权。该学得的参考在当前窗内固定。
3. **当前的比较目标。** 将 W192 固定分为三个不重叠的 64 点块，各拆为两半。每个候选延迟在一个 32 点半块 \(A\) 内拟合相同的截距和符号约束增益
   \[
   (\hat c_{A,d},\hat a_{A,d})
   =\arg\min_{c,\ a\ge0}\;\operatorname{mean}_{t\in A}
     (z_{t,j}-c-a\,s z_{t-d,i})^2.
   \]
   另一半测量 \(E_{A\to B}(d)\)；互换两半重复。替代模板与原模板在两个半块中的绝对中心化相关都低于 0.95，两者都须有足够数值方差。仅当两半选择**同一个**替代延迟 \(d'\)，且各自在拟合半块的误差低于原延迟时，计算
   \[
   D_{j,b} = \frac{\max(0,\min(E_{A\to B}(d_0)-E_{A\to B}(d'),\;
                                 E_{B\to A}(d_0)-E_{B\to A}(d')))}
                       {\operatorname{Var}_{t\in b}(z_{t,j})}.
   \]
   其他情况取零。每块取 \(D_b=\max_jD_{j,b}\)，稀疏改变无需对全通道对平均。绝对残差机制对照分数使用同一批历史合格边、相同的原延迟拟合与方差除数，取跨半块原延迟误差的均值后再对响应变量取最大。当前平移或缩放在覆盖整个有效块且历史参考固定时可由同一截距／增益族吸收，滤波接缝处另行评价。交叉确认的两半可有时间依赖，因此把它当作预测检验分数。
4. **训练与最终评分。** 阶段一直接复用已验证源端点和 LEFT 原生训练损失，候选没有额外深网参数，也不增加训练更新。附加的关系学习是上述法方程。阶段一独立正常 SOURCE SELECT 上，冻结该检查点，分别封存原生点分数和经过“最大边”的块分数参考样本。设 \(p_S(v)=(1+\#\{q\in S:q\ge v\})/(|S|+1)\)，最终分数
   \[
     S_t=\max\{-\log p_{\rm LEFT}(L_t),\; -\log p_{\rm delay}(D_{b(t)})\}.
   \]
   使用原生分数、仅原生经验秩、原生秩加绝对残差、原生秩加确认时延四个同缓存读出。弃权的 \(D_b=0\) 且参考样本非负，延迟项因此为零。经验尾秩有并列和截断，秩对照用来识别它本身的影响。重叠源窗、最大筛选与目标域变化均限制校准的解释，这里不声称目标假阳性概率保证。
5. **目标使用规则。** Z 固定模型、源尾秩分布和全部常数。U 使用既有同预算普通源重放更新 LEFT，机制对照和候选共用这一个 U 端点。按更新后的权重在同一独立正常 SOURCE SELECT 重估 LEFT 尾秩。关系规则和其源参考分布固定，在线历史仍取本记录严格过去。混合目标数据只作为既有无标签重放输入。F 可在固定独立有标签支持集上通过三点网格 \(\delta\in\{-\log2,0,+\log2\}\) 为正的关系证据增减一个对数偏移，零证据保持零，取类别均衡、异常事件等权的逻辑损失加 \(0.1\delta^2\) 最小值。逻辑截距固定为独立 SOURCE SELECT 的原联合分数 q99，平局选最小绝对偏移再取较小值。所有模型和历史规则在 F 保持固定，此处 F 是少标签融合适配。任何用于汇报目标报警率的阈值仅从其后固定独立 CAL 拟合，没有合法 CAL 时记 NA。本次最小验收只覆盖 Z 评分程序。该目标适配规则尚无污染鲁棒证据。

## 与最近方法的区别

| 方法 | 已有计算 | 可直接检验的区别 |
|---|---|---|
| 原生 LEFT | 联合时域、频域、多尺度窗口重构和一致性判据 | 同一 LEFT 端点和原分数。附加证据要求一个替代统计响应在未参与选滞后的观测中也胜过冻结正常时延 |
| Heppel 等，DX 2024 | 从估计的父变量学习各变量正常条件分布，依条件分布异常程度打分 | 普通条件残差是本方案的机制对照。候选另比较解释偏离的替代滞后，并对同样的增益和偏置进行剖面拟合 |
| 工业过程时延识别 | 用相关和差分等办法识别过程时延 | 本方案固定过去选择的参考、比较同一响应的两种结构，并用交叉确认的误差收益做检测评分。时延识别、预白化和最小二乘属于已有工具 |
| CrossAD | 利用跨尺度预测和跨窗口查询库做检测 | 此处的历史固定驱动、符号和正常滞后，不检索其他窗口去重构当前响应 |
| 项目旧关系头／残差 | 预测 Pearson 关系或直接测条件残差，大量关系经平均 | 新统计量检验稀疏边上的替代滞后是否通过双向验证。完整方案仍需超过相同历史和残差的对照 |

重点是该受限判据对异常排序的价值。检索已经排除把滞后识别、统计条件建模或残差加权本身写成新贡献。相近工业结构变化检验是否已实现相同的双半块复核及融合仍待系统查重。若等预算残差对照表现相当，当前差异不足以支持方法贡献。 [LEFT](https://arxiv.org/abs/2602.08638) · [Heppel 等](https://drops.dagstuhl.de/entities/document/10.4230/OASIcs.DX.2024.11) · [工业时延识别](https://www.sciencedirect.com/science/article/pii/S0967066117300655) · [CrossAD](https://proceedings.neurips.cc/paper_files/paper/2025/hash/c9658e8c20879632cb1cfca91d80ceb7-Abstract-Conference.html) · [公开基准中的跨通道异常边界](https://arxiv.org/abs/2606.02670)
