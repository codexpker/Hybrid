# History-reference-consistent source training

Two native TimeRCD models share the official checkpoint and all original parameters/heads. No residual branch is installed. For each single generated process, R=x[0:512] and X=x[512:1024] are disjoint. Only X enters the encoder and losses. Training compares batch mean/std over X against mean/std of each corresponding R. Both use sample std plus1e-4 as the original source collate. Both source SELECT evaluations use R statistics and the same fixed masks; joint CE+masked original-input MSE selects checkpoints including step0. Source labels only, not target labels. Final B inference retains original FIT population statistics and its original zero-std handling; no claim of identical finite-sample estimators.

The pinned official generator is used through a separately hashed controlled copy. Its univariate/DAG global centering/range and noise range statistic are restricted to the first512 points. Original files remain untouched. Candidates are accepted in seed order only when original generator labels are zero throughout R and actual R equals its generated normal R. This is eligibility rejection, not detection-performance selection. Original suffix Y is retained; no fabricated propagation labels. X normal counterfactual is never saved in the training bank or used to determine reference statistics. All R/X copies share one instance group and one role.

Fixed seed2025; FIT1536 and SELECT256 generated instances; batch3, three epochs/1536 updates, each FIT instance exposed three times. AdamW1e-4, weight decay1e-5, gradient clip1; full original backbone and both heads update. Patch16 masks use floor(32*.15)=4 patches (12.5% effective). Every source validation uses identical reference statistics. This is a bounded synthetic-supervised continuation with auxiliary self-supervision, not pure unsupervised or proven mixed-contamination robustness.

Normal-reference support is a controlled synthetic assumption, not an established explanation for previous failures. Both arms use the same accepted instances, so source-distribution changes relative to old training are shared. Old continuation is historical only, not a matched control.

PSM and all28 SMD entities use unchanged B-only FIT normalization, window5000/batch1, raw head logit difference and original CAL q99/higher strict-greater thresholds. Both are offline exposed development evaluations. Entire bank set must seal before labels are opened. No target-result feedback changes the recipe.
