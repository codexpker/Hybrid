# SWaT 旧 LEFT 权重的同轴全窗与末点比较

复用 seed2025 的四组检查点及原 FIT-only scaler。noU 是原受限 SWaT 正常训练的已选检查点，恢复原评分运行步 `36992`。U-A、U-B、U-C 均为原普通 U 的第 2,000 次更新终点，运行步 `38992`。A 为原背景，B 为真实攻击供体替换，C 为同来源正常替换。四组均恢复原生推理状态并核对检查点、角色和 scaler 身份。本轮只做评分，训练更新为 0。

原生 `model.infer` 使用 31 通道、192 点窗口、192 步长和绝对起点 `495000` 的网格，保留每个窗内所有输出位置并取作者的 float32 通道均值。CAL 的 255 个完整输入窗覆盖 `[446040,495000)`，均位于旧 CAL 角色 `[445661,495000)` 内。原 512 个校准点全部有合法分数。QUERY 的 1,752 个完整输入窗覆盖 `[608472,944856)`，均位于旧 QUERY 角色 `[608023,944919)` 内。两种读出共同评价 `[608535,944856)` 的 336,321 点，尾部 63 点不参加本次比较。全窗分数可用时间为所在窗的末点，因此这是离线回顾。末点各行取自原缓存，裁轴后复算。

VUS 采用官方提交 [`3fadb481`](https://github.com/DezhengWang/Left/tree/3fadb4811797075e233076b9faceb0d8ec59b697) 的 `metricor.RangeAUC_volume_opt`，`windowSize=100`、`thre=250`。严格点级指标对每种读出用各自合法 CAL 的同一组 512 点计算 `q99 / higher`，报警使用严格大于。只在全部 8 个新分数文件封存且阈值计算完成后读取标签。本轮仅列点级误报和召回，未计算新的事件或延迟指标。

## 技术决定与计算记录

本次全窗结果仍呈现普通 U 的排序与操作点取舍。U-B 在本次固定任务上的排序正项得到保留，B 相比 C 的低召回和低误报同时成立。这一对照不支持一致的污染特异退化，也不足以支持污染鲁棒性。任何下一项学习增量应以**同一训练条件的普通 U**为主要匹配对照，沿用相同训练权限、全窗读出、CAL 和 QUERY。noU用于量化目标更新本身的变化。 [作者协议正常训练结果](../left_native_swat_20261118/RESULTS.md)的 AP 为 0.543249，使用更宽的正常训练和标准化权限及不同评价轴，仅作权限分列的外部参考。原末点及截尾、随机保留结果留在各自既有记录。

4 个 A40 推理进程均正常退出，分别占卡 9.37、11.57、11.65、11.56 秒，合计 44.14 秒（0.012262 GPU 小时）。主 CPU 评价用时 164.97 秒。一次职责分离的同模型家族独立复算用时 146.83 秒，核对的 72 个数值完全一致。无新增训练、重选权或后继作业。
