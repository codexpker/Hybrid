# Shared NASA LEFT comparison

Each spacecraft uses one complete LEFT model initialized from the fixed official implementation, trained at seed2025 on its admitted entities' original normal training arrays. MSL27 uses sensor0 and W96; SMAP53 uses sensor0 and W192. Each entity's first80% supplies stride-one FIT windows and last20% supplies nonoverlapping validation windows. Windows never cross entity or role boundaries. A domain-level StandardScaler is fitted on all admitted normal training observations including their validation parts. Test statistics are excluded. This includes project historical CAL regions, so independent-CAL operations for LEFT are NA.

Training follows the fixed author entry point: Adam1e-4, batch128, type1 learning-rate schedule, at most20epochs and patience3, selected by normal validation. MSL's alpha_casd_l/s fields are explicitly mapped to alpha_ms_l/s using the original values0.5/0.3. The original config files are preserved. This is a project-compatible implementation, with the complete model, original losses and original infer score.

The selected state_dict restores parameters and prototype buffers. The official train entry retains the final Python model.step, which is absent from state_dict, and inference uses the original curriculum schedule through _forward. Selected and final steps and warmup/ramp stages are recorded. No additional training or alternative runtime-step choice is made from test results.

The original TRAIN.json field target_values_or_labels_in_training=false refers to excluded test values and labels. The official target-normal training arrays were intentionally used. Its unambiguous permissions are SOURCE=the domain's public normal train arrays, SELECT=per-entity final20%, TEST=unread until training/selection finished. The implementation field was clarified for future invocations; original run receipts remain preserved.

Each entity test record uses its own complete nonoverlapping input windows and every output position. Scores are available at each containing window's endpoint. Full scored axis is [0,Wfloor(N/W)); tails are unscored. Shared comparison with current causal detectors uses [99,Wfloor(N/W)). Each metric is computed per entity before equal-domain averaging. VUS uses the fixed LEFT metric implementation, windowSize100 and250 thresholds. No test labels select model or score.
