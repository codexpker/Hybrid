# Standard supervised readout on frozen TimeRadar features

## Fixed method and source permissions

TimeRadar plus supervised MLP is a project baseline. The official pretrained encoder, fractional-order network, decoder, parameters and buffers remain frozen. Each native W100, patch-five forward uses B1 and the original ten complementary masks, with isolated seed 84551. The encoder output is reshaped to [10,1,C,20,256]. Real and imaginary features concatenate to 10,240 coordinates for each copy/channel. A shared 10,240→64→1 GELU MLP produces each local logit, and their copy/channel mean gives the window score. Both learning and deployment use this window scalar. The public event label does not identify which sensor is faulty.

The fixed loss has three positive terms: 0.5 times the point-count-weighted positive softplus(−logit), 0.25 times the same-weight paired-normal softplus(logit), and 0.25 times the nominal-normal mean softplus(logit). This compares a complete discriminative learning/readout procedure against native V supervision. It changes the learned parameters and objective as well as inference, so any gap cannot be uniquely attributed to the score alone.

SOURCE roles, five FIT events, four SELECT events, normal windows, scalers and the seed-2025 sealed 240-step plan are reused. Two fixed rates, 1e-4 and 1e-3, share an identical head initialization and actual per-window frozen encoding. Each uses a separate fresh source-configured AdamW, with 24-step warmup, through 2,400 updates and ten passes of the same plan. At each step the learner sees 32 nominal windows and 15 abnormal/15 normal pair windows. The labeled source positives and paired normals retain the existing legal-positive-point-count weights. SOURCE SELECT uses the corresponding three-term balanced BCE, equal weighting across event/time strata, and the original nominal panel. All selection occurs before target scoring.

## Completed source learning

Both the formal full-range and the ≤240-step auxiliary rule chose learning rate 1e-3 at step 40, risk 0.458484785, versus step-zero risk 0.697997583. The best 1e-4 checkpoint was step 280 with risk 0.464565247. The two selected heads have equal parameter tensors; target inference computes the head once and records both specified rows. They cannot be interpreted as independent observations.

The MLP has 655,489 trainable parameters. Per learning-rate trajectory, the full search used 148,800 window exposures and 11,560 distinct endpoint windows, which can overlap in time and do not constitute additional events. The selected step-40 head used 2,480 exposures and 2,326 distinct endpoint windows. The formal search considered later checkpoints even though it ultimately selected an early state. The ≤240-step row constrains exposure at selection while retaining the two-rate development allowance. It does not establish total-compute or trainable-capacity equality with the native decoder trials.

The source task was learned with generalization limits. At lr1e-3, the final FIT loss was 0.166287 while final SELECT risk was 2.104022; the source-only rule retained the early minimum. No target metric determined this choice. This evidence permits interpreting target transfer of the chosen supervised head, with source overfitting reported separately.

## Public evaluation permissions

PSM uses its complete causal ranking axis [99,87841), 87,742 endpoints with 25 variables, and the separate 64,728-point historical suffix for operation. Its 512 CAL points all have attack labels, so q99 is an empirical operation point and does not certify a normal false-alarm budget. MSL27 and SMAP53 use sensor zero and per-entity [99,N) axes, averaging entities equally. Their small per-entity CAL sets make q99/higher the maximum. Long steady coverage has only four MSL and ten SMAP events. SMD uses all 28 separate machines and all 38 channels; its nominal training records contributed source windows. SOURCE-event supervision came from SWaT, and SMD test labels did not enter training or head selection.

Each selected head scores every legal CAL and QUERY window at its actual endpoint with raw logits. Each readout has its own threshold from the same legal CAL positions, q99/higher, strict exceedance. Confirmed alarms begin at the third consecutive crossing without backfill. Any-hit and one-to-one event matching remain separate. Coverage reports both equal-event and pooled values after the first 512 event points. Misses remain distinct from hit-only delays.

External methods keep their original training and context permissions. LEFT, CATCH and PCA can be compared on a separate PSM intersection [512,87744); the prior LEFT/HistoryMean512 panel extends to 87841. SMAP external and native results intersect at [512,N); SMD LEFT uses [99,192 floor(N/192)). The MSL historical flattened external bank has uncertified entity boundaries. Missing compatible external rows stay missing. Shared scored points do not remove the offline future context used by a comparator.

## Completed public comparison

[Full method and operating tables](TABLES.md) · [full-precision method values](methods.csv) · [paired differences](paired.csv) · [compatible external panels](EXTERNAL.md)

The same source-selected supervised MLP scored all four public tasks. Its AP/ROC-AUC/VUS-PR/VUS-ROC were 0.50494/0.72168/0.45263/0.60520 on PSM; 0.28168/0.55090/0.31698/0.62785 on MSL; 0.28896/0.53892/0.31272/0.59110 on SMAP; and 0.37652/0.75892/0.31839/0.76763 on SMD28. Each of these four domain metrics is lower than the existing seed-2025 supervised-V result on its matched axis. The AP gaps (MLP minus V supervision) are −0.07223, −0.07244, −0.09376 and −0.06554. These are four fixed-task comparisons, with entity means within NASA and SMD; there is only one project seed for the MLP.

The chosen MLP had improved source SELECT risk, so its transfer result cannot be described simply as failure to optimize the source task. Its later validation overfitting remains material: the two fixed rates and complete search retained the early minimum, and no target-selected repair was made. This baseline tests whether a standard window classifier on the frozen representation reproduces the existing source-supervised detector's cross-task ranking. It did not in this fixed study. The comparison changes trainable components, score, objective and effective selected exposure together. It does not separately prove a variance-specific mechanism, independent FRFT contribution, universal superiority to discriminative learning, target U/F efficacy or contamination robustness.

Operating results add tradeoffs. Under PSM's unchanged attack-only CAL, MLP three-confirmation normal FPR was 0.02424 versus V supervision's 0.05919, recall 0.24272 versus 0.37333, one-to-one matches 7 versus 10 of 48, and normal fragments 48 versus 93. Event F1 nevertheless rose from 0.10638 to 0.11667 because the predicted-alarm count changed; any-hit fell from 11 to 8. Macro/pooled long coverage fell from 0.53069/0.73561 to 0.35564/0.52927, and the longest miss increased from 874 to 1,228 points.

On MSL, MLP three-confirmation matched 21 rather than 24 of 35 events and generated 401 rather than 165 normal fragments. Its long macro coverage was lower but pooled coverage higher; only four long events qualify. On SMAP, MLP recall and long coverage were higher, with 1,388 normal fragments versus 808 and 30 rather than 36 one-to-one events. The ten-event long macro/pooled coverages were 0.30394/0.57695 versus 0.20322/0.44445. On SMD, MLP generated 1,069 versus 1,305 normal fragments and had event F1 0.15819 versus 0.14236, while normal FPR rose from 0.18468 to 0.19079. Recall, matches and long coverage fell: matches 112 versus 123 of 327, long macro/pooled 0.52634/0.61032 versus 0.57300/0.69816. Macro coverage gives events equal weight; pooled coverage weights their point counts. Neither any-hit nor event F1 substitutes for either definition.

The PSM external intersection [512,87744) gives AP 0.50667 for MLP, 0.57763 for V supervision, 0.57733 for native offline LEFT, 0.53463 for PCA and 0.44684/0.43112/0.43365 for the three archived CATCH seeds. The source-label and target-normal-training permissions differ. LEFT's complete-window inference has offline context. The archived PSM causal LEFT/HistoryMean512 and the SMD LEFT and SMAP external panels use their own stated shared axes. Missing entity-resolved MSL external scores remain missing.

**Technical decision.** Retain the standard supervised MLP as a completed source-label baseline. This fixed head did not match the current V candidate's cross-task ranking, although its operation points have specific benefits and costs. Retain the V candidate's task-dependent Z evidence and the NASA absolute-performance and SMD boundaries established in prior comparisons. Current U and F recipes remain closed. The baseline provides no grounds to promote either method to an established complete mixed-unlabeled solution. No head, learning rate, source window, threshold or target entity was changed after target evaluation.

## Verification, cost and artifacts

The frozen feature extractor matched the complete native H exactly on a normal source window; its RNG state was restored. The official parameters and buffers remained identical, while only the 655,489 MLP parameters updated. The source-only comparison contains the same five FIT and four SELECT events. Two rates were optimized independently over shared frozen window encodings. Each target uses its own archived scaler and legal calibration points, with actual endpoint footprint retained. No target intermediate feature bank was stored; sealed score banks, weights and necessary identities remain on the experiment server, with SHA receipts in the repository.

Successful dual-trajectory source learning used 1,233.23 A40-seconds (0.34256 hours) on one device, including shared encoding and source validation. An exclusive-create curve writer failed at its first refresh, about 29 seconds; its original artifacts were retained. Source snapshots were repaired without changing the scientific configuration. The source total including that estimate is 0.35062 A40-hours. Successful four-domain scoring used 6,685.15 A40-seconds (1.8570 hours), so the combined recorded total is approximately **2.208 A40-hours**. The NASA exact-window deduplication key required flattening its singleton sensor axis; four failed input attempts made zero target-model forwards, with 0.040 seconds measured inside failed entity handling. Separate module startup overhead was not timed and remains NA. Successful banks were reused after recovery. CPU metrics and external cache intersections add CPU cost rather than GPU forward cost.
