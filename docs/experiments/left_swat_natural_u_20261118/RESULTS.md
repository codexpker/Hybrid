# SWaT 原生 LEFT 初态的自然混合普通 U

两组均从 [已验证的作者协议基准](../left_native_swat_20261118/RESULTS.md) 起步。noU 直接裁取原生分数缓存。普通 U 恢复同一第 14 轮权重、原型和原评分运行步 `52581`，使用同一 scaler 和作者评分。固定 seed2025、批量 128、Adam `1e-4`、全参数和原生完整损失，完成 2,000 次有效更新，使用终点 `54581`。窗口起点在 U-FIT 内的全部合法 192 点起点中均匀有放回抽取，训练只从连续观测 `[495000,585000)` 取值。旧供体身份、标签和分类掩码未进入训练。新任务与原受限 A/B/C 分开归档。

`[585000,585544)` 为隔离间隔。新 CAL 角色 `[585544,607479)` 的健康状态在取点时未知。以 `495000` 为锚点、窗长和步长 192，113 个合法 CAL 整窗覆盖 `[585624,607320)`，从中固定取 `np.linspace(585624,607319,512,dtype=int64)`。两组分别以自身的 `q99 / higher` 为阈值，报警使用严格大于。该规则给出混合 CAL 的经验操作点，目标 QUERY 正常误报率由数据决定。旧 CAL 在原生初始化的数据权限内。

QUERY 同轴 `[608535,944856)`，共 336,321 点。全窗分数在窗末点才可用。noU 派生缓存重建可用时间字段，原档与分数值保持原样。VUS 使用 LEFT 固定源 `metricor.RangeAUC_volume_opt`，`windowSize=100`、`thre=250`。两组均报告离线回顾结果。

QUERY 有 47,777 个攻击标签点及 288,544 个正常标签点。两组的 CAL 严格超阈点数均为 5/512。训练终点、两组分数及阈值固定后统计，U-FIT 有 5,187/90,000 个攻击标签点，CAL 角色有 1,657/21,935 个，512 个预定 CAL 点中有 38 个。CAL 点的标签仅供事后说明，未用于取点或阈值。

普通 U 的 ROC-AUC 和 VUS-ROC 分别增加 4.31 和 5.30 个百分点，AP 和 VUS-PR 分别降低 1.22 和 0.44 个百分点。固定操作点的召回下降 38.01 个百分点，误报增加 176 点。这一结果建立了同域正常背景初始化后，在连续自然混合数据上进行普通无标签更新的比较对象。当前配对只能识别这次更新的整体效果，缺少等权限的正常后续更新对照来分离污染本身的影响。旧 A/B/C 和截尾结果沿各自原协议归档。本轮未追加计算。

GPU0 单作业退出码 0，训练与评分共占 156.256 A40 秒（0.043404 GPU 小时），其中训练 147.688 秒。noU 仅用缓存，CPU 裁取与评价 30.46 秒。普通 U 的 CPU 评价用时 27.83 秒。同模型家族、职责分离的一次独立结果复算用时 48.19 秒，两组 20 项数值与主表完全一致。
