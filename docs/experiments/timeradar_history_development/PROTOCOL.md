## Fixed source and training contract

Both targets share one candidate source model and one independently trained native decoder control. Normal TEP FaultFree Training uses the previously standardized 52 process variables, FIT runs1–20 and SELECT runs61–65. Normal SMD uses all 28 machines, 38 variables, record-wise first80% FIT and remaining20% SELECT. The standardizers use only their original source FIT. Variable number varies between source records; neither arm changes variable identity or order. All complete 256+100 or 512+100 footprints stay in one source record and one role. PSM and SWaT are both excluded from project source learning. The official checkpoint retains its own upstream permissions.

The immutable `plans.npz` contains 240 common source batches of32, 16 records from each source, and the same32-window normal SOURCE SELECT panel for both methods. It also stores a shared 2,000-step replay stream of16 source windows and per-target16-slot U plans. Sampling seed2025 is independent of the official fixed-mask Torch RNG. Source checkpoint selection is earliest minimum of full-window copy MSE at steps0/40/80/120/160/200/240. The same source-selected model is used on both targets. Source SELECT records copy MSE, mean-output E and sample variance V at every checkpoint.

Source optimizer is fresh AdamW1e-4, beta=(0.9,0.95), eps1e-8, ordinary weight decay0.1, bias/LayerNorm0, 24-step warmup. U independently restores its own arm's selected source model and uses fresh matched AdamW for2,000 fixed-endpoint updates, 200-step warmup, logical batch32 (16 target,8 TEP,8 SMD). Each window is native B1 with ten fixed complementary masks, norm0, native nondecoder frozen, all native modules eval. The history arm adds its trainable history/interaction parameters to the decoder optimizer. The control has decoder parameters only. All training gradients come from the same native copy objective. Each logical loss is divided by32 before backward. Metadata records full numeric plan hashes and source tensor identities.

## Diagnostics and F preparation

The first actual training logical batch records finite loss, parameter-group gradients, memory, elapsed time and the exact terminal scalar V for correct history, a time-reversed replacement and bypass. The time-reversal is an engineering path intervention. A subsequent sealed-model panel uses the fixed source SELECT windows and, where available, an earlier nonoverlapping512-point history in the same record/role. TEP cannot supply two nonoverlapping256-point histories in one500-point run and is NA for that comparison.

F is prepared by an offline qualification process using only U-FIT public labels. It chooses the first complete abnormal event with eligible full100-point current windows and612-point input footprints, plus the earliest512-point label-normal block that yields a legal current window. History labels are not requested by the learner. Label and history budgets are recorded separately. The learner receives only frozen612-point numeric footprints and the prescribed copy/pair plan. Both arms begin at their complete source checkpoints, with no U intermediate. F uses240 fixed AdamW updates with24-step warmup,32 copy windows,15 event/normal pairs, coefficient1, margin1 and log1p V transform, with source point-count weights across three chronological event strata. The common scale is the official model median V on all eligible normal support endpoints (floor1e-8). There is no target-performance selection. The support eligibility receipt may reveal very few independent normal windows, which limits later F interpretation.
