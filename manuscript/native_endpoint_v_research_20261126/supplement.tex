\texttt{881e8912e4c5b298b202e5b7ac2fe58107c7dcf1b56acf733e28c99f2ffc0317}.
Its initial checkpoint SHA-256 is
\texttt{528aea6e803f9e6b1ea5d07e64e44162309bdb016cc7721a8ac3753d942e6c7c}.
The seed 2025 plan hash is
\texttt{df7e74047bb0fd49d25a2da0bb58e54a2fbe3327fd9f61b6e07ceca6422543e9}.
The official source model is loaded with
\texttt{seq\_len=100,\ hidden\_dim=64,\ d\_model=256,\ depth=10,\ patch\_len=5,\ mask\_mode=\textquotesingle{}c\textquotesingle{}}.
The existing raw source and checkpoint identities are preserved. This
writing task produces no model artifacts.

Masks are generated with isolated seed 84551. One tensor of shape
\([5C,20]\) contains five masks of shape \([C,20]\). Appending its
complement yields a bank reshaped to \([10,C,20]\), restored for each
window with channel count C. Batch membership therefore cannot change
the order of a scored window. Source and target scalers are applied
before the native forward, whose norm option is 0. Eval mode disables
dropout throughout the project decoder fitting. No ordinary no\_grad
inference call is used for the differentiable pair term.

The registered official model has 1,636,043 parameters. The method
updates the 793,610 parameters of the original decoder and adds zero
parameters. All other native parameters and buffers are fixed. Scores
retain full observed current windows and are causal reconstruction
scores. They are not forecasts from strictly past-only inputs.

\subsection{Data origins, project versions and metric
software}\label{data-origins-project-versions-and-metric-software}

Primary distributions are cited in the main text. Project identity is
additionally fixed by archived array hashes. PSM uses the 25-channel
arrays with 132,481 normal-prefix points and 87,841 test points recorded
in AXES\_AND\_INPUTS.json. SMD uses all 28 original machines and 38

shapes are retained in MSL\_NATIVE\_MEMBERS.json, together with the
archived SMAP mapping and pre-existing P-2 exclusion. The primary
telemetry publication does not by itself specify this project's
single-sensor or admission choices. SWaT uses the archived
physical-process arrays and fixed 31-channel map.

\texttt{10.7910/DVN/6C3JR1}, Version 1. The two files are
\texttt{TEP\_FaultFree\_Training.RData} and

run split and injection timing are in the
\href{../../docs/experiments/native_tep_support_20261125/INPUT.json}{TEP
source manifest}. They do not enter the formal endpoint method.

The original VUS article defines the measure. The VUS repository is its
reference software distribution, while this study called the metric file

\href{../../src/hybrid_tsad/left_native_swat_metrics.py}{left\_native\_swat\_metrics.py}.

\texttt{808a07460a84d31c87edce1d803e1df231111ec53ffa702ee32eb54a79897dfc},

parameters. Neither the dataset paper nor current VUS package defaults
determine these recorded results.
\href{../../docs/experiments/native_endpoint_external_20261125/EVALUATION.json}{The

\section{S4 Operational evaluation}\label{s4-operational-evaluation}

Every operating result uses its original legal CAL locations and each
model's own threshold. No threshold was chosen from these tables. PSM
evaluates {[}23016,87744), separate from the full causal ranking axis.
Its 512 CAL points all have attack labels. NASA q99/higher equals the
maximum of the small eligible CAL sample. SMD CAL records are nominally
normal. These are empirical operation points without certified normal
error budgets.

Strict and three-confirmation rows remain distinct. Three-confirmation
has no backfill. The same absolute indices are used to preserve
continuity. One-to-one event matching uses the archived chronological
interval matching implementation and requires overlap of predicted and
true intervals with each interval used at most once. Any-hit counts true
events with any alarm and need not agree with matching. Only complete
eligible events enter event coverage. Long steady coverage begins 512
points after onset. No-eligibility entries remain NA.

For multi-entity tasks, point and event counts are first pooled across
entities within a seed, while long-event macro coverage weights eligible
long events equally. These are different from the equal-entity ranking
means. Displayed fractional matched counts and false-fragment counts
arise from averaging training seeds.
